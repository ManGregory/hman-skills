# My learning

My private learning repository for the [mentor skill](https://github.com/ManGregory/hman-skills/tree/main/plugins/mentor).

Each topic is a folder with a `learning-plan.md`, and each subtopic keeps its session notes, assessments and `results.json`. The mentor commits and pushes after each session, so the history is in `git log`.

## Start a session

Open this repository in Claude Code (terminal, desktop app, web, or the Code tab in the mobile app) and say what you want to learn:

> Let's continue with git basics

> I want to learn Kubernetes from scratch

`.claude/settings.json` installs the mentor plugin automatically for this repository. Settings live in `.mentor.json`.

`example-git-basics/` shows what a topic looks like after one session. Delete it when you no longer need it.
