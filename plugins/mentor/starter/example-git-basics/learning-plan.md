# Git Basics Learning Plan

> Example topic. Delete this folder once you have started your own topics.

## Goal
Use git confidently for day-to-day work: branches, merges, and fixing mistakes without panic.

## Background
- **Experience:** Has used `git add`, `commit` and `push` from an IDE; never worked with branches from the command line
- **Use case:** Joining a team that uses pull requests
- **Starting mental model (2026-01-10):** "A branch is a copy of the whole project"
  - Misconception: a branch is a movable pointer to a commit, not a copy
- **Setup mode:** quick start

## Teaching Preferences
- **Style:** hybrid
- **Language:** English
- **Notes:** Likes small diagrams of commit graphs
