## Prior Knowledge Check
Uses git through the IDE. Thinks a branch copies the whole project.

## Concepts Covered
- A commit is a snapshot with a pointer to its parent
- A branch is a movable pointer to a commit
- HEAD points to the current branch
- `git switch -c` creates and switches in one step

## Dialogue & Learning

**Mentor:** Before we start: what do you think happens on disk when you create a branch?

**Student:** it copys all the files into a new folder somewhere?

**Mentor:** That's a very common guess. Let's test it: run `git branch test`, then check the size of `.git`. Did it grow by the size of your project?

**Student:** no, it basically didnt change. so its not a copy

**Mentor:** Right. A branch is a 41-byte file holding one commit id. If a branch is just a pointer, what do you think moves when you make a new commit?

**Student:** the pointer of the branch im on moves to the new commit

## Key Insights
- Branches are cheap because they are pointers, which is why teams create one per change

## Confusion Points
- Detached HEAD: what it means when HEAD points at a commit instead of a branch
